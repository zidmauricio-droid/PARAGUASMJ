¿Qué es la Bitácora de Operación?

Es el libro físico que lleva el fontanero / operador de turno con sus registros diarios (lecturas de caudal, cloro, presión, novedades, etc.).

Este módulo no genera datos digitales. Solo permite subir el escaneo (PDF o foto) del libro para dejarlo archivado en el sistema con código GA-BIT como soporte documental ante la SSPD y la CAR.
